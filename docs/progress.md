# 开发进度

最后更新：2026-10-09。开发分支 `phase1-foundation`，版本 0.2.0（界面 `web/` 0.3.0）。
每次告一段落时更新这份文档：已完成的挪到「已完成」，新发现的问题加到「已知问题」。

---

## 当前状态

- **能用、每天在用**：
  - 台式机 BASE 当主机，数据在 `D:\xpanel`。
  - 其他电脑通过局域网连接；或者各用各的数据文件夹，用外置硬盘按条目合并（见 [drive-sync.md](drive-sync.md)）。
- **界面**：
  - 新界面（`web/`，React）是默认界面，旧界面（`ui/index.html`）挂在 `/old/`，只修严重问题。
  - 用户对外观要求高，改界面前先看 [development.md](development.md) 第 3 节的设计规则。
- **测试**：
  - Rust 部分有单元测试和接口测试。
  - 界面靠 Playwright 脚本手动测，脚本不在仓库里。
  - 最近几批功能都只在浏览器里模拟测过，还没在真实桌面版上全部走一遍（见待办）。

## 已完成

### 基础（phase 1–2）

- Rust 工作区：`xp-core`（模型和逻辑）、`xp-store`（SQLite，软删除，版本号，每日备份和冷备份，操作记录，API key）、`xp-server`（axum，v1 兼容接口 + `/api/v1` + SSE + OpenAPI）、`xp-cli`（`xp` 命令行 + MCP）、`xp-workspace`（笔记展开成项目目录）、`src-tauri`（桌面版，主机和连接两种模式，离线队列）。
- 事项三栏、优先级和截止日期、分类树和标签、设备（心跳上报在线状态和 IP）、入口（按机器分组）、收件箱、微信聊天记录导入、交给 AI（终端里的 Claude Code / Codex 等）、AI 通过 MCP 回写进展。
- 提交规则由 `.githooks/commit-msg` 强制检查；历史已压缩成一个初始提交 `d0a11b3`。

## 已知问题

| 问题 | 说明 |
|---|---|
| 用 Esc 关对话框后，下一次点击会被吞掉 | 只在桌面版（WebView2）出现；点 × 或点外面关闭没事。试过先改状态再卸载，没解决。按 Ctrl+Alt+D 打开调试面板，可以看事件记录 |
| 离线时和别处冲突的修改看不到 | 连接模式下离线的修改补传时，如果主机上那条已被别处改过，会被拒绝并记到本机的 `rejected.json`，界面上还没有入口 |
| 块悬停底色有时停在最后一块 | 鼠标移到编辑区下方空白处时，最后一块的浅底色不消失 |
| 「整篇按 Markdown 重新排版」会去掉代码块里的空行 | 为了修复每行一段的代码块，代码块内的空行一起去掉了 |
| Codex 的 token 用量没在真实环境验证 | 按 codex 新旧两种事件格式做了兼容，只用构造的样例测过；读不到时只是不显示 |
| 连接模式离线时看不到图片和附件 | 本机只缓存条目，附件每次向主机取 |
| 块编辑器的包比较大 | `BlockEditor` 分块约 720KB（已改成第一次进编辑时再加载） |
